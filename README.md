# Pinnawala Elephant Tour & Luck Uyana Cabana

A modern, responsive single-page web application built with **Next.js (App Router)** and **Vanilla CSS** for **Pinnawala Elephant Tour**, representing Pinnawala's premier accommodations and restaurants: **Luck Uyana Cabana** and **Pinnawala Reach** in Sri Lanka.

## Key Features

- **Tranquil Luxury Design**: Designed with a calm, serene aesthetic, generous whitespace, and responsive layouts across all devices.
- **Multilingual Support**: Real-time language switching across **English**, **Russian (Русский)**, and **German (Deutsch)**.
- **Elephant Experiences & Ethical Charter**: Detailed schedules for daily river baths, nutritious feeding, mahout heritage, and a dedicated animal welfare charter.
- **Twin Accommodation Showcase**:
  - **Luck Uyana Cabana**: 4 private eco-luxury cabanas nestled in palm gardens.
  - **Pinnawala Reach**: 7 luxury boutique rooms near the Maha Oya river.
- **Authentic Restaurant & Culinary Section**: Featuring on-site garden dining, clay-pot curries, and tropical breakfast spreads.
- **Living Ayurveda Herbal Medicine Garden**: Interactive botanical guide to native Ceylon spices and traditional wellness infusions.
- **Custom Island Itineraries**: 1-Day to 7-Day itineraries with day-by-day breakdowns.
- **Curated Categorized Gallery**: Lightbox image modal with categories for Stays, Elephants, Herbal Garden, Restaurant, and Surroundings.
- **Direct WhatsApp & Booking Engine**: Form with automated instant WhatsApp query compiler (+94 77 190 8272) and confirmation dialog.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the assigned port) to view the site.

### Build

```bash
npm run build
```

## CI/CD Deployment

This repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the static application to **GitHub Pages** on every push to the `main` branch.
